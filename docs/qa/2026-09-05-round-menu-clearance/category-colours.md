# Category colour is product data; DATA is not a transport

Mattias's latest feedback supersedes the all-white category presentation.
The reusable icon catalogue still owns geometry only. Showcase's typed product
palette owns five meaningful navigation categories: style/layout mint,
controls/icons gold, text blue, audio violet, and data cyan. Utility actions
remain warm white; category colour is not evidence of online/fresh status.

The existing launch atom now receives an optional semantic colour on the same
Phone/Round path, as rows already did. Generated family colours come from the
compiled product palette, not an Android colour table or glyph default.
DATA and DATA AGE bind the published shared `data` geometry (assets 0.3.61).
Wi-Fi is no longer used to mean arbitrary data or background work.
