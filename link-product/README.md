# Link Product

This is the smallest second-product proof for the shared ProductSpec stack.
It composes the published `position.service` skydiving Lego into one `POSITION`
page and emits deterministic Kotlin declarations. It contains no Skyvw source,
app, runtime or renderer.

The slice intentionally stops at Kotlin emission. The generated files describe
the native seam; they do not fabricate a runtime merely to make a sample build.
